## Design Patterns

- React function components + hooks
- CSS modules avoided — global CSS with `rz2-` / `rz-` prefixes
- Font: **Share Tech Mono** (Google Fonts)
- Visual tone: near-black `#030203`, crimson accents, grain/scanline FX
- Canvas already used on homepage for tunnel rat animation (not a game engine)
- Firebase for infection stats (unrelated to containment game)

## Safest Integration Point

1. Add route **`/containment`** in `App.tsx`
2. New page `ContainmentProtocol.tsx` wrapping feature module
3. Entry link on `Transmission.tsx` footer (alongside Infection Station)
4. Feature code under `src/features/containment/` — isolated from PFP infection code
5. Styles: `src/styles/containment.css` using existing palette + semantic `--containment-*` tokens

## Recommended Renderer

**HTML Canvas** — matches spec, performant for hex board + particles, keeps simulation separate from React render loop. No PixiJS/Phaser needed for ~25 rooms.

## Existing Risks

- Large single JS bundle (~518 kB) — containment will increase size; consider lazy route import later
- Internal filenames/hooks use legacy `Ratzilla` naming — must not appear in user-facing UI
- No ESLint — rely on TypeScript strict + Vitest
- Firebase config required for infection stats (containment does not depend on it)
- `html, body { overflow: hidden }` on homepage — containment page needs its own scroll/overflow rules
